## 📸 Демонстрация

### Главная страница | Страница товара

---

## 💡 Возможности

- ✅ Главная страница с карточками товаров (5+ наборов)
- ✅ Отдельная страница для каждого товара с подробным описанием
- ✅ Адаптивная верстка (корректно отображается на телефонах и планшета)
- ✅ Единый CSS-файл (легко менять дизайн всего сайта)
- ✅ Навигационное меню и футер на всех страницах

🚀 Как запустить
Скачайте репозиторий (ZIP или git clone).

Откройте файл index.html любым браузером (двойной клик).

✅ Никаких серверов и установок не требуется — это чистый фронтенд.

Для разработки удобно использовать VS Code с расширением Live Server.
